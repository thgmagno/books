# 🚀 Quick Start — Book Notes App

## Seu app está aqui:
```
/home/claude/book-notes-app
```

## 1️⃣ Prepare seu GitHub

```bash
# Vá para https://github.com/new
# - Name: book-notes-app
# - Private: ✓
# - Clique em "Create repository"
# - Copie a URL HTTPS
```

## 2️⃣ Faça o push

```bash
cd /home/claude/book-notes-app

git remote add origin https://github.com/SEU-USUARIO/book-notes-app.git
git branch -M main
git push -u origin main
```

## 3️⃣ Deploy no Railway

```
1. Vá para railway.app
2. Login com GitHub
3. New Project → Deploy from GitHub repo
4. Selecione book-notes-app
5. Pronto! 🎉
```
